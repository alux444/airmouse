# AirMouse design

AirMouse is a small, calm native utility. The main task is starting and stopping pointer tracking with confidence; the connection state, recovery message, sensitivity and shortcut stay visible beside it.

Use a warm off-white canvas, deep forest control surface and light lime action. SF system typography and SF Symbols keep the interface native. The motion illustration is decorative, never the only indication of state. The menu bar provides a persistent way to pause and reopen the window.
